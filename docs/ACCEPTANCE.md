# Homebot.app 验收清单（给 Felix）

2026-10-25，S16 之后的版本（`mac/VERSION` = `0.1.0`）。发布前的清单和发布说明草稿见 [RELEASE.md](RELEASE.md)。代理没有推送、打标签、发布或公证任何东西。

## 1. 从零安装

按 [INSTALL.zh-Hans.md](INSTALL.zh-Hans.md)：解压 → 拖进“应用程序” → 打开 → “Not Opened” → 完成 → 系统设置 › 隐私与安全性 › 仍要打开（这一步是你自己点）。

- [ ] 顺手截一张“仍要打开”那一行的图（中文、英文系统各一张更好），放到 `docs/images/install/`，指南里这张图还空着。
- [ ] 从“下载”直接打开一次：如果 macOS 把它放进临时位置（App Translocation），应看到“把 Homebot 移到‘应用程序’”的提示且“登录时打开”被拒绝；没有放进临时位置时只显示“不在‘应用程序’里”的提醒。移过去后正常。
- [ ] “仍要打开”之后 macOS 是否还会再问一次（指南写的是“如果再问”）。

## 2. 设置流程（四步）

- [ ] **账号**：检测到 Grok Bot 登录（有登录时可点“改用 API 密钥”）；没有登录时直接粘贴 Cursor API 密钥并保存。主页显示 Grok Bot 是否接受。
- [ ] **Bot**：按准确名字添加（输入两次）。打错字会让 Grok Bot 新建空 Bot，Homebot 不添加（这一步会真的在账号里建 Bot，想测再测）。
- [ ] **快捷指令**：语言选择器从“新快捷指令的默认语言”开始；英文默认短语依次是 “Grok Bot / My Grok Bot / Our Grok Bot”；只有 `/ \ :`、控制字符、开头的点、超过 60 个字符或与其他 Homebot 快捷指令重名会阻止，其余只是建议；按钮是“用 Apple 签名并生成”，下面一行说明会发给 Apple 什么，点一下就算同意；之后按钮变回“生成快捷指令”，设置 › 这台 Mac 里可以关掉“用 Apple 签名快捷指令”。
- [ ] **安装 › 这台 Mac**（同一个 Apple 账户）：添加到快捷指令 → 在弹出的窗口点“添加快捷指令” → “在这台 Mac 上问一次”里点“试一试” → 始终允许 → 输入问题 → 听到回答，这一行打勾。
- [ ] **安装 › iPhone**：扫码或隔空投送 → 添加快捷指令 → 在快捷指令 App 里点一下 → 问一句 → 回答后这一步显示已回答。
- [ ] 在 **设置** 里打开“登录时打开”，保持“为 Siri 让这台 Mac 保持唤醒”。

## 3. 设备检查（来自 STATUS S16，需要你）

- [ ] 这台 Mac 路径端到端（见上），以及该行自动打勾。
- [ ] iCloud：快捷指令出现在 iPhone 上，不用再允许一次（或多久问一次），HomePod 上也能用。
- [ ] Mac 路径上的替换：先删旧的再添加；同名导入时 iOS 是“替换”还是生成改名副本。
- [ ] 同步提示里的路径：iPhone“设置 › App › 快捷指令”，Mac“快捷指令 › 设置”。
- [ ] 删掉快捷指令库里的探测快捷指令 “HB Install Probe 1”、“2”、“3”。
- [ ] 中文：中文 HomePod +“Grok Bot”，问一个问题，听到正确回答。
- [ ] 英文：英语 Siri +“Grok Bot”，问一个问题，听到正确回答。
- [ ] 用英文问中文快捷指令（或反过来）：Bot 是否用提问的语言回答。
- [ ] 对话模式（“每次回答后继续听”，只用于单个 Bot 的快捷指令）：回答后继续听，说结束词能结束。
- [ ] “Siri 为什么没读出来？”：如果 iPhone 只显示文字不朗读，改成“偏好朗读”后是否会读。
- [ ] 单入口快捷指令（“我的所有 Bot”）：iPhone 和 HomePod 上的编号菜单。
- [ ] 注销再登录后 Homebot 自己启动，Siri 仍能用。

## 4. 外观

- [ ] 浅色、深色：主页、四步设置、快捷指令列表、设置、帮助。悬停只变颜色，不跳动。
- [ ] 快捷指令列表：状态圆点（绿：可用，橙：需要更新，灰圈：还没回答过）、“安装”按钮、“⋯”菜单（安装到另一台 iPhone、更改语言、对话模式、撤销）。
- [ ] 应用图标“自动”随浅色/深色切换；访达只在图标样式为“深色”时显示黑色。
